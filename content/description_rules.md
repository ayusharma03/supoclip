# Viral Pods: title and description rules

Rules for every Short / Reel posted to @pod_cuts14 (YouTube) and @pod_cuts14 (Instagram).
Claude follows this file when writing titles, descriptions and captions; edit it to change the style.

## Credit (always, no exceptions)

Every post credits the original creator and links the full episode.

| Key | Creator | Show | YouTube | Instagram |
|---|---|---|---|---|
| `prakhar` | Prakhar Gupta | Prakhar ke Pravachan | https://www.youtube.com/@ThePrakharGuptaXperience | _(fill in, e.g. @handle)_ |

- YouTube description: a credit line plus the link to the exact source video.
- Instagram caption: a credit line with the creator's Instagram handle when it is filled in above
  (links are not clickable in captions, so no URL there).
- Never imply we are the creator or that the creator endorses this page.
- New creator: add a row before posting their clips.

## Tone

- Natural, like a person who watched the clip and wants a friend to see it. Not a marketer, not a bot.
- Write in the language of the clip. Prakhar's clips are Hinglish, so the description is casual Roman
  Hinglish ("bhai ye baat sabko samajhni chahiye"), with English words left in English.
- Focused on this clip only: the one idea, question or moment in it. No summary of the whole episode.
- Concrete over vague: name the actual point ("first job sirf ek accident hota hai"), not
  "an amazing insight about life".
- No clickbait he didn't say, no ALL CAPS, at most 1 emoji, no "must watch", "mind-blowing",
  "you won't believe".

## Title (YouTube) / first line (Instagram)

- 40–70 characters, Hinglish or English, whichever sounds more natural for the clip.
- The hook of the clip, phrased as the viewer's thought or question.
  Good: "20s mein sabse badi galti yahi hoti hai". Bad: "Prakhar Gupta podcast clip #3".
- No hashtags in the title.

## YouTube description layout

```
<1–2 lines: what this clip is about, in the clip's own words/voice>

<optional 1 line: why it matters or the question it leaves you with>

🎙️ Credit: <Creator> (<Show>)
Full episode: <source video URL>

#shorts #<topic> #<creator tag> #podcastclips #viralpods
```

## Instagram caption layout

```
<title line>

<1–2 lines about the clip>

🎙️ Credit: <Creator> (<Show>) <Instagram handle if known>
Full episode on their YouTube channel.

#<topic> #<topic> #<creator tag> #podcastclips #hinglish #viralpods
```

## Hashtags

- 5–7 total. 2–3 about the clip's topic (#career, #20s, #entrepreneurship, #money, #mindset ...),
  1 creator tag (#prakhargupta), plus #podcastclips and #viralpods.
- YouTube: #shorts is added automatically by the uploader; don't repeat it in the list.

## Checks before posting

- The quote or claim in the description is actually said in the clip.
- Subtitles read correctly (no garbled words); otherwise hold the clip.
- Near-duplicate of an earlier clip (same point from another episode)? Post only the better one.

## GTA clips (preset `gta`)

Everything above applies, with these changes.

- **Credit:** the streamer, with their channel and the exact stream link
  (`🎮 Credit: <Streamer> (<channel>)` / `Full stream: <URL>`). Add each streamer as a row in the
  credit table before posting their clips.
- **Tone:** like a friend sending a clip in the group chat: short, playful, Hinglish
  ("bhai police ne literally chhoda hi nahi 😂"). One emoji allowed here.
- **Title:** what happens, not a quote: the chase, the fail, the reaction
  (Good: "Police se bachne ke chakkar mein khud hi phas gaya". Bad: "GTA 5 funny moment #12").
  Name the server or RP character only when the clip makes it obvious.
- **Description:** 1 line setting up the moment, without giving away the ending.
- **Hashtags:** 5–7: #gta5 or #gtarp, 1–2 about the moment (#police, #heist, #funny),
  the streamer's tag, #gaming and #viralpods. Instagram adds #gtaindia.
- **Check:** no slurs or abuse in the burned-in subtitles; hold clips where the payoff is off-screen.
